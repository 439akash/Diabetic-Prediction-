# DiaPredict Healthcare Dashboard

This project contains two ways to run the DiaPredict dashboard:

## 1. Professional Development Version (Recommended)
This version uses **Vite** and **React** for the best performance and development experience.

### How to Run:
1.  Open this folder in **VS Code**.
2.  Open the Terminal (`Ctrl + ``).
3.  Run `npm install` to install dependencies.
4.  Run `npm run dev` to start the development server.
5.  Open the link shown in the terminal (usually `http://localhost:5173`).

---

## 2. Standalone Version (No Install Required)
This version runs in a single HTML file and uses a local server script.

### How to Run:
1.  Run the `serve.py` script:
    *   `python serve.py`
2.  Open `http://localhost:8000/standalone-dashboard.html` in your browser.

---

## Project Structure
*   `src/`: React source code (App, Components).
*   `standalone-dashboard.html`: The all-in-one version.
*   `lib/`: Local copies of required libraries (React, Recharts, etc.).
*   `tailwind.config.js`: Configuration for the design system.
